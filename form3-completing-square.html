Lesson 1 of 4

What Completing the Square Means

Builds on: Unit 2: expanding brackets. Unit 4: perfect square trinomials, (x + h)² = x² + 2hx + h².

Goal: By the end of this lesson I can explain, using an area diagram, why x² + bx needs the term (b/2)² added to become a perfect square.

1 Key ideas

  • In Unit 4 you learned to factorize a perfect square trinomial like x² + 6x + 9 into (x + 3)². Completing the square asks the opposite question: given x² + 6x (which is NOT a perfect square), what must be added to make it one?
  • Picture it as area. x² + bx is a square of side x, plus two matching rectangles of width b/2 — together they form an L-shape (a gnomon) with a small square-shaped corner missing.
  • The missing corner has side b/2, so its area is (b/2)². Adding this completes the big square, of side (x + b/2).
  • This gives the key identity: x² + bx = (x + b/2)² − (b/2)². We add (b/2)² to complete the square, and subtract the same amount so the value of the expression does not change.
  • Completed-square form is (x + h)² + k. It looks different from x² + bx + c, but for the same values of x, it gives exactly the same output — the two forms are equivalent.
  • Once b is a fraction (for example, b = 5, so b/2 = 2.5), the method is exactly the same — just work with the fraction or decimal carefully.

Reading the area diagram

Common mistakes

  • Adding b instead of (b/2)² — for x² + 6x, adding 9 is correct, not 6 or 3.
  • Forgetting to halve b before squaring — (b/2)² is not the same as b²/2 for most values.
  • Thinking the missing corner's side is b, when it is actually b/2 (there are two rectangles sharing the b between them).

Lesson 2 of 4

Completing the Square for x² + bx + c

Builds on: Lesson 1, and collecting like terms (Unit 2).

Goal: By the end of this lesson I can rewrite any monic quadratic x² + bx + c in completed-square form (x + h)² + k.

1 Key ideas

  • The rule: x² + bx + c = (x + b/2)² − (b/2)² + c. The h in (x + h)² is always half of b.
  • Method: (1) Halve b to get h. (2) Write (x + h)². (3) Subtract h² (to "cancel out" the extra amount you introduced). (4) Combine the subtracted h² with c to get the final k.
  • So the completed-square form is (x + h)² + k, where h = b/2 and k = c − h².
  • Check your answer by expanding (x + h)² + k and confirming you get back x² + bx + c.
  • This works whether b is positive or negative. If b is negative, h is negative too — for example, x² − 8x has h = −4, giving (x − 4)².
  • Extension (ax² + bx + c, a ≠ 1). If the coefficient of x² is not 1, first factor a out of the x² and x terms only, then complete the square inside the brackets.

3 Worked examples

Example 2.1

Positive b, simple case

Write x² + 6x + 11 in completed-square form.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. b = 6, so h = 6 ÷ 2 = 3.
  2. Write (x + 3)², which expands to x² + 6x + 9 — that is 9 = 3² too many.
  3. Subtract 9 and add the original 11: (x + 3)² − 9 + 11 = (x + 3)² + 2.

Answer: (x + 3)² + 2

Example 2.2

Negative b

Write x² − 8x + 5 in completed-square form.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. b = −8, so h = −8 ÷ 2 = −4.
  2. Write (x − 4)², which expands to x² − 8x + 16.
  3. Subtract 16 and add the original 5: (x − 4)² − 16 + 5 = (x − 4)² − 11.

Answer: (x − 4)² − 11

Example 2.3

Checking by expanding

Check the previous example by expanding (x − 4)² − 11.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. (x − 4)² = x² − 8x + 16.
  2. (x − 4)² − 11 = x² − 8x + 16 − 11 = x² − 8x + 5.
  3. This matches the original expression.

Answer: Confirmed

Example 2.4

Odd b (a fraction appears)

Write x² + 5x + 1 in completed-square form.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. b = 5, so h = 5 ÷ 2 = 2.5.
  2. (x + 2.5)² expands to x² + 5x + 6.25.
  3. Subtract 6.25 and add 1: (x + 2.5)² − 6.25 + 1 = (x + 2.5)² − 5.25.

Answer: (x + 2.5)² − 5.25

Think: Fractions and decimals are common in completing the square. Would it be easier for you to work with 2½ and 5¼, or with 2.5 and 5.25?

Example 2.5

When c is already the right amount

Write x² + 12x + 36 in completed-square form.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. b = 12, so h = 6.
  2. (x + 6)² expands to x² + 12x + 36 exactly.
  3. There is nothing left over: k = 36 − 36 = 0.
  4. So x² + 12x + 36 = (x + 6)² + 0 = (x + 6)².

Answer: (x + 6)²

Think: This is a perfect square trinomial, like the ones you factorized in Unit 4. Completing the square and factorizing a perfect square trinomial give the same result here.

Common mistakes

  • Forgetting to add the original constant c back in after subtracting h².
  • Sign errors with negative b, such as writing (x + 4)² instead of (x − 4)² for x² − 8x + 5.
  • Leaving the answer as (x + h)² − h² + c instead of simplifying to (x + h)² + k.

Lesson 3 of 4

Using Completed-Square Form to Find the Minimum Value

Builds on: Lesson 2, and plotting coordinates (earlier units).

Goal: By the end of this lesson I can use completed-square form to state the minimum value of a quadratic, its turning point, and its axis of symmetry, without drawing the graph.

1 Key ideas

  • For y = x² + bx + c, the graph is a parabola (a U-shaped curve) that opens upward, because the coefficient of x² is positive.
  • In completed-square form, y = (x + h)² + k. Since (x + h)² is a squared term, it can never be negative — its smallest possible value is 0, which happens when x = −h.
  • So the minimum value of y is k, and it occurs when x = −h. The turning point (vertex) of the graph is the point (−h, k).
  • Watch the sign carefully: if the completed-square form is (x + 3)² + 2, the turning point is (−3, 2), not (3, 2) — the x-coordinate is the opposite sign of the number inside the bracket.
  • The axis of symmetry is the vertical line through the turning point: x = −h. The curve is a mirror image of itself on either side of this line.
  • This method finds the exact minimum value without plotting a single point — a powerful shortcut compared with drawing a table of values and a graph.

3 Worked examples

Example 3.1

Finding the minimum value and turning point

y = x² − 6x + 11. Write this in completed-square form, then state the minimum value of y, the turning point, and the axis of symmetry.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Complete the square: h = −3, h² = 9, k = 11 − 9 = 2. So y = (x − 3)² + 2.
  2. The minimum value of y is 2, occurring when x = 3.
  3. The turning point is (3, 2).
  4. The axis of symmetry is x = 3.

Answer: Minimum value 2 at x = 3; turning point (3, 2); axis of symmetry x = 3

Example 3.2

Reading the graph to confirm

The graph shows y = x² − 6x + 11. Confirm that the graph matches the answer from the previous example.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. The lowest point on the curve is at (3, 2), matching our turning point.
  2. The curve is symmetric about the vertical line x = 3.
  3. For every x-value, the point directly opposite across x = 3 gives the same y-value — for example, y(2) = 3 and y(4) = 3.

Answer: Confirmed

Example 3.3

A different sign of h

y = x² + 4x + 9. Find the minimum value, the turning point, and the axis of symmetry.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Complete the square: h = 2, h² = 4, k = 9 − 4 = 5. So y = (x + 2)² + 5.
  2. The minimum value is 5, when x = −2 (the opposite sign of the +2 in the bracket).
  3. The turning point is (−2, 5). The axis of symmetry is x = −2.

Answer: Minimum value 5 at x = −2; turning point (−2, 5)

Example 3.4

Using the minimum value in context

The height, in metres, of a cable above a valley floor is modelled by h(x) = x² − 10x + 34, where x is the horizontal distance in metres. Find the lowest point of the cable.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Complete the square: half of −10 is −5, (−5)² = 25. k = 34 − 25 = 9.
  2. h(x) = (x − 5)² + 9.
  3. The minimum value of h is 9, when x = 5.
  4. The lowest point of the cable is 9 m above the valley floor, at x = 5 m.

Answer: 9 m above the valley floor, at x = 5 m

Think: Why is knowing the minimum value useful here, compared with just knowing the equation?

Common mistakes

  • Writing the turning point as (h, k) instead of (−h, k) — the x-coordinate changes sign.
  • Confusing the axis of symmetry (a whole line, x = a number) with just a single point.
  • Trying to find the minimum value from x² + bx + c directly, without completing the square first.

Lesson 4 of 4

Solving Quadratic Equations by Completing the Square

Builds on: Lessons 2–3. Unit 4: solving quadratics by factorizing.

Goal: By the end of this lesson I can solve a quadratic equation by completing the square, including when the answers are not whole numbers.

1 Key ideas

  • In Unit 4, you solved quadratic equations that factorize neatly. Completing the square gives a method that works for every quadratic equation, even ones that do not factorize with whole numbers.
  • Method: (1) Complete the square to write the equation as (x + h)² + k = 0. (2) Rearrange to (x + h)² = −k. (3) Take the square root of both sides, remembering both the positive and negative root: x + h = ±√(−k). (4) Solve for x.
  • ± means "plus or minus" — a quadratic equation usually has two solutions, one from each sign.
  • If −k is negative (that is, k is positive), there is no real solution, because you cannot take the square root of a negative number. This matches a minimum value that never reaches zero.
  • Always check your solutions by substituting them back into the original equation.
  • This method connects directly to Lesson 3: the equation x² + bx + c = 0 asks "where does the graph cross the x-axis?", while the minimum value from Lesson 3 tells you whether it crosses at all.

3 Worked examples

Example 4.1

A simple case

Solve x² − 2x − 3 = 0 by completing the square.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Complete the square: h = −1, h² = 1, k = −3 − 1 = −4. So (x − 1)² − 4 = 0.
  2. Rearrange: (x − 1)² = 4.
  3. Square root both sides: x − 1 = ±2.
  4. So x = 1 + 2 = 3, or x = 1 − 2 = −1.

Answer: x = 3 or x = −1

Example 4.4

An equation that does not factorize neatly

Solve x² + 4x − 2 = 0 by completing the square, giving your answers to 2 decimal places.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Complete the square: h = 2, h² = 4, k = −2 − 4 = −6. So (x + 2)² − 6 = 0.
  2. (x + 2)² = 6.
  3. x + 2 = ±√6 ≈ ±2.449.
  4. x ≈ −2 + 2.449 = 0.45, or x ≈ −2 − 2.449 = −4.45.

Answer: x ≈ 0.45 or x ≈ −4.45

Think: Try to factorize x² + 4x − 2 using whole numbers. Why does it not work? This is exactly when completing the square is essential.

Example 4.5

No real solution

Solve x² + 4x + 9 = 0 by completing the square. What happens?

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Complete the square: h = 2, h² = 4, k = 9 − 4 = 5. So (x + 2)² + 5 = 0.
  2. (x + 2)² = −5.
  3. There is no real number whose square is negative, so there is no real solution.

Answer: No real solution

Think: Look back at Lesson 3: the minimum value of x² + 4x + 9 is 5, which is positive. What does that tell you about whether the graph ever crosses the x-axis?

Common mistakes

  • Forgetting the ± sign, and giving only one solution instead of two.
  • Trying to take the square root of a negative number without recognising there is no real solution.
  • Sign errors when moving from (x + h)² = m to x = −h ± √m.
