Lesson 1 of 5

What Is a Set?

Builds on: Number facts: factors, multiples, primes, odd and even numbers (the warm-up).

Goal: By the end of this lesson I can describe and list a set, use ∈ and ∉, find n(A), and say whether a set is finite or infinite.

1 Key ideas

  • A set is a well-defined collection of objects. Well-defined means we can always decide whether an object belongs to the set or not. {tall students} is not well-defined, because people will disagree about who is tall. {students taller than 160 cm} is well-defined.
  • The objects in a set are called its elements (or members). We name sets with capital letters and write the elements inside braces { }, separated by commas.
  • ∈ means "is an element of" and ∉ means "is not an element of". If A = {2, 4, 6}, then 4 ∈ A and 5 ∉ A.
  • There are three ways to describe a set. In words: A = {even numbers less than 8}. By listing: A = {2, 4, 6}. In set-builder notation: A = {x : x is an even number, x < 8}. The colon ":" is read as "such that".
  • Order does not matter, and each element is listed only once: {a, b, c} = {c, a, b}. The letters of the word BANANA form the set {B, A, N}.
  • n(A) means the number of elements in A. If A = {2, 4, 6}, then n(A) = 3.
  • A finite set has a number of elements that we can count, and the counting ends. An infinite set goes on forever. We use an ellipsis (…) to show that a pattern continues: {2, 4, 6, 8, …} is infinite. {1, 2, 3, …, 100} is finite, because the list stops at 100.

3 Worked examples

Example 1.1

Listing a set

List the elements of A = {days of the week beginning with T}. Find n(A).

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Go through the days one at a time: Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday.
  2. Keep only the days that start with T: Tuesday and Thursday.

Answer: A = {Tuesday, Thursday}, so n(A) = 2.

Example 1.2

Repeated elements

List the set of letters in the word ANTIGUA and find its number of elements.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. The letters in order are A, N, T, I, G, U, A.
  2. The letter A appears twice, but a set lists each element only once.

Answer: {A, N, T, I, G, U}, so n = 6 (not 7).

Think: Why do you think a set does not count repeats? What question does a set answer: "how many times?" or "which ones?"

Example 1.3

Describing a set in words

Describe B = {2, 3, 5, 7} in words.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Look for what the elements have in common. 2, 3, 5 and 7 each have exactly two factors, so they are all prime.
  2. Check for any primes that are missing: 2, 3, 5 and 7 are all the primes less than 10.

Answer: B = {prime numbers less than 10}

Think: {prime numbers less than 11} is also correct. Can one set have more than one correct description in words?

Example 1.4

Using ∈ and ∉

P = {factors of 18}. Say whether each statement is true or false: (a) 6 ∈ P (b) 4 ∈ P (c) 18 ∉ P

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. First list P: 18 = 1 × 18 = 2 × 9 = 3 × 6, so P = {1, 2, 3, 6, 9, 18}.
  2. (a) 6 is in the list, so the statement is true.
  3. (b) 4 is not in the list, so the statement is false.
  4. (c) 18 is in the list, so "18 is not an element" is false.

Answer: (a) True (b) False (c) False

Example 1.5

Finite or infinite?

State whether each set is finite or infinite: (a) {multiples of 5} (b) {grains of sand on Dickenson Bay beach} (c) {1, 2, 3, …, 500} (d) {fractions between 0 and 1}

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. (a) 5, 10, 15, 20, … never ends, so the set is infinite.
  2. (b) There are a huge number of grains, but the number is not endless. In theory they could be counted, so the set is finite.
  3. (c) The ellipsis is followed by a last element (500), so the set is finite.
  4. (d) Between any two fractions there is always another one (for example, halfway between them), so the set is infinite.

Answer: (a) infinite (b) finite (c) finite (d) infinite

Think: Part (b) shows that "very large" is not the same as "infinite".

Example 1.6

Set-builder notation

List the elements of C = {x : x is an integer, −2 ≤ x < 3}.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Read it as: "C is the set of all x such that x is an integer and x is between −2 and 3".
  2. −2 ≤ x means −2 IS included. x < 3 means 3 is NOT included.
  3. The integers from −2 up to (but not including) 3 are −2, −1, 0, 1, 2.

Answer: C = {−2, −1, 0, 1, 2} and n(C) = 5

Common mistakes

  • Listing an element more than once, e.g. {C, O, C, O, N, U, T}.
  • Thinking that a very large set must be infinite.
  • Forgetting to check whether the ends of an inequality are included (≤) or not included (<).

Lesson 2 of 5

Comparing Sets: Equal, Equivalent, Empty and Subsets

Builds on: Lesson 1: listing sets and finding n(A).

Goal: By the end of this lesson I can decide whether two sets are equal or equivalent, recognise the empty set, and list all the subsets of a set.

1 Key ideas

  • Equal sets have exactly the same elements (order does not matter). {1, 2, 3} = {3, 1, 2}.
  • Equivalent sets have the same number of elements: n(A) = n(B). {a, b, c} and {1, 2, 3} are equivalent but not equal. Every pair of equal sets is also equivalent, but equivalent sets are not always equal.
  • The empty set (or null set) has no elements. We write it as ∅ or { }. For example, {months with 32 days} = ∅. Note that {0} is not empty. It has one element, the number 0.
  • A is a subset of B, written A ⊂ B, if every element of A is also an element of B. {2, 4} ⊂ {1, 2, 3, 4}. If A is not a subset of B, we write A ⊄ B.
  • Every set is a subset of itself, and the empty set is a subset of every set. Why? To show A ⊄ B, you must find an element of A that is not in B. The empty set has no elements, so you can never find one. The rule is never broken.
  • A set with n elements has 2ⁿ subsets. Each element can either be in a subset or not, so there are 2 choices for each element. A proper subset is any subset except the set itself, so there are 2ⁿ − 1 proper subsets.
  • Be careful with ∈ and ⊂. If A = {2, 4, 6}, then 2 ∈ A (2 is an element), but {2} ⊂ A ({2} is a set).

3 Worked examples

Example 2.1

Equal or equivalent?

A = {1, 2, 3}, B = {3, 1, 2}, C = {x, y, z}. Compare the sets.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. A and B have exactly the same elements in a different order, so A = B.
  2. A and C each have 3 elements, but the elements are different. So A and C are equivalent but not equal.

Answer: A = B. A and C are equivalent (n(A) = n(C) = 3).

Example 2.2

Recognising the empty set

Which of these sets are empty? (a) {even prime numbers greater than 2} (b) {0} (c) {months with 32 days} (d) {x : x is an integer, 3 < x < 4}

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. (a) The only even prime is 2, so there are none greater than 2. The set is empty.
  2. (b) This set contains the number 0. It has 1 element, so it is not empty.
  3. (c) No month has 32 days, so the set is empty.
  4. (d) There is no integer between 3 and 4, so the set is empty.

Answer: (a), (c) and (d) are empty. (b) is not.

Example 2.3

Listing subsets systematically

List all the subsets of S = {a, b, c}.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Work by size so that you do not miss any.
  2. 0 elements: ∅
  3. 1 element: {a}, {b}, {c}
  4. 2 elements: {a, b}, {a, c}, {b, c}
  5. 3 elements: {a, b, c}

Answer: There are 8 subsets. 8 = 2³, which matches the rule 2ⁿ.

Think: Look at the pattern: a set with 0 elements has 1 subset, 1 element gives 2, 2 elements give 4, and 3 elements give 8. Why does the number double each time you add an element?

Example 2.4

Subsets and elements

A = {2, 4, 6, 8}, B = {even numbers less than 10}, C = {4, 8}. True or false? (a) C ⊂ A (b) A = B (c) {2} ∈ A

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. (a) 4 and 8 are both in A, so C ⊂ A is True.
  2. (b) B = {2, 4, 6, 8}, which has the same elements as A. True.
  3. (c) The elements of A are numbers, not sets. The number 2 is an element, so 2 ∈ A. But {2} is a set, so the correct statement is {2} ⊂ A. The statement is False.

Answer: (a) True (b) True (c) False

Example 2.5

Counting subsets

How many subsets and how many proper subsets does a set with 5 elements have?

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. The number of subsets is 2⁵ = 2 × 2 × 2 × 2 × 2 = 32.
  2. The proper subsets are all of these except the set itself: 32 − 1 = 31.

Answer: 32 subsets, 31 proper subsets

Common mistakes

  • Thinking {0} is the empty set.
  • Forgetting ∅ and the set itself when listing subsets.
  • Mixing up ∈ (for an element) and ⊂ (for a set).

Lesson 3 of 5

Universal Set, Complement, Union, Intersection and Venn Diagrams

Builds on: Lesson 2: subsets and the empty set.

Goal: By the end of this lesson I can find A ∪ B, A ∩ B and A′, draw a Venn diagram for two sets, and describe shaded regions using set notation.

1 Key ideas

  • The universal set U contains all the elements being considered in a question. In a Venn diagram, U is drawn as a rectangle, and the other sets are circles inside it.
  • The complement of A, written A′, is the set of elements in U that are not in A. This means n(A) + n(A′) = n(U).
  • The intersection A ∩ B is the set of elements that are in A and in B (in both). It is where the circles overlap.
  • The union A ∪ B is the set of elements that are in A or B or both. Each element is listed only once.
  • If A ∩ B = ∅, then A and B are disjoint: they have no elements in common, so their circles do not overlap.
  • If A ⊂ B, then circle A is drawn completely inside circle B.
  • A two-set Venn diagram has four regions: A only (A ∩ B′), both (A ∩ B), B only (A′ ∩ B) and neither ((A ∪ B)′).
  • How to draw a Venn diagram: (1) fill in the intersection first, (2) then the "only" regions, (3) then the elements outside both circles. Check that every element of U appears exactly once.

3 Worked examples

Example 3.1

Union, intersection and complement

U = {1, 2, 3, …, 10}, A = {even numbers}, B = {multiples of 3}. Find A ∩ B, A ∪ B, A′ and (A ∪ B)′. Then draw a Venn diagram.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. List the sets: A = {2, 4, 6, 8, 10} and B = {3, 6, 9}.
  2. In both: A ∩ B = {6}.
  3. In either or both (list each once): A ∪ B = {2, 3, 4, 6, 8, 9, 10}.
  4. Not in A: A′ = {1, 3, 5, 7, 9}.
  5. Not in A ∪ B: (A ∪ B)′ = {1, 5, 7}.
  6. Draw the Venn diagram: put 6 in the overlap first, then 2, 4, 8, 10 in A only, then 3, 9 in B only, then 1, 5, 7 outside the circles.

Answer: A ∩ B = {6}, A ∪ B = {2, 3, 4, 6, 8, 9, 10}, A′ = {1, 3, 5, 7, 9}, (A ∪ B)′ = {1, 5, 7}

Think: Check: n(A) + n(A′) = 5 + 5 = 10 = n(U). Why must this always be true?

Example 3.2

Disjoint sets and subsets

U = {1, 2, …, 12}, P = {prime numbers}, Q = {4, 8, 12}, R = {2, 3}. Describe how P and Q are related, and how R and P are related. Show both in Venn diagrams.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. P = {2, 3, 5, 7, 11}. P and Q have no elements in common, so P ∩ Q = ∅. They are disjoint: draw two circles that do not touch.
  2. Every element of R is in P, so R ⊂ P. Draw circle R inside circle P.

Answer: P ∩ Q = ∅ (disjoint sets). R ⊂ P (R is inside P).

Example 3.3

Reading a Venn diagram

Use the Venn diagram to list: A, B, A ∪ B, A′, A ∩ B′ and (A ∩ B)′.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. A = everything inside circle A = {a, b, c}.
  2. B = everything inside circle B = {c, d, e, f}.
  3. A ∪ B = everything inside either circle = {a, b, c, d, e, f}.
  4. A′ = everything outside circle A = {d, e, f, g, h}.
  5. A ∩ B′ = in A and not in B = A only = {a, b}.
  6. (A ∩ B)′ = everything except the overlap = {a, b, d, e, f, g, h}.

Answer: A = {a, b, c}, B = {c, d, e, f}, A ∪ B = {a, b, c, d, e, f}, A′ = {d, e, f, g, h}, A ∩ B′ = {a, b}, (A ∩ B)′ = {a, b, d, e, f, g, h}

Example 3.4

Shading regions

Shade each region on a Venn diagram: A ∩ B, A ∪ B, A′, A ∩ B′.

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. A ∩ B: shade only the overlap.
  2. A ∪ B: shade both circles completely.
  3. A′: shade everything outside circle A, including the part of B that is not in A.
  4. A ∩ B′: shade the part of A that is not in B (the crescent shape).

Answer: See the four diagrams.

Think: A useful strategy: shade the first set with vertical lines and the second set with horizontal lines. For ∩, keep the region where the lines cross. For ∪, keep every region that has any lines.

Common mistakes

  • Listing an element twice in a union, e.g. {1, 2, 3, 3, 4}.
  • Writing A ∩ B = 3 instead of A ∩ B = {3}. An intersection is always a set.
  • Forgetting the elements outside the circles when finding a complement.

Lesson 4 of 5

Venn Diagrams with Three Sets

Builds on: Lesson 3: two-set Venn diagrams and the order of filling them in.

Goal: By the end of this lesson I can draw a three-set Venn diagram and describe any of its regions using set notation.

1 Key ideas

  • Three overlapping circles make 8 regions: the centre (all three sets), three "two sets only" regions, three "one set only" regions, and the region outside all the circles.
  • Fill from the centre outwards: (1) A ∩ B ∩ C, (2) each pair only, e.g. A ∩ B ∩ C′, (3) each single set only, e.g. A ∩ B′ ∩ C′, (4) outside, (A ∪ B ∪ C)′.
  • Before placing each element, ask three questions: Is it in A? Is it in B? Is it in C? The three answers tell you exactly which region it goes in.
  • Some region names: "A and B but not C" = A ∩ B ∩ C′. "A only" = A ∩ B′ ∩ C′. "In none of the sets" = (A ∪ B ∪ C)′.
  • Check your diagram. Every element of U must appear exactly once, and the numbers in all 8 regions must add up to n(U).

Lesson 5 of 5

Solving Problems with Venn Diagrams

Builds on: Lessons 3 and 4: Venn diagrams and n(A). This lesson also uses algebra: forming and solving a simple equation.

Goal: By the end of this lesson I can use n(A ∪ B) = n(A) + n(B) − n(A ∩ B), and use x and an equation to solve Venn diagram word problems.

1 Key ideas

  • n(A ∪ B) = n(A) + n(B) − n(A ∩ B). We subtract n(A ∩ B) because the elements in the overlap were counted twice: once in n(A) and once in n(B).
  • In word problems we often put numbers in the regions instead of listing elements.
  • When the overlap is unknown, call it x. Then A only = n(A) − x and B only = n(B) − x.
  • All the regions together make up the universal set. So the sum of all regions = n(U). This gives an equation that you can solve for x.
  • In three-set problems, start with the centre, then work outwards. Subtract as you go.
  • Useful words: "only" means one region. "Both" usually means the whole overlap. "Neither" or "none" means outside the circles. "At least one" means the union.

Example 5.2

Finding x (CSEC style)

In a Form 3 class of 35 students, 20 play cricket (C), 18 play football (F) and 4 play neither sport. x students play both. (a) Draw a Venn diagram. (b) Write an equation and solve it for x. (c) How many students play cricket only?

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. (a) Put x in the overlap. Cricket only = 20 − x. Football only = 18 − x. Neither = 4.
  2. (b) All the regions add up to the class size: (20 − x) + x + (18 − x) + 4 = 35.
  3. Simplify: 42 − x = 35, so x = 7.
  4. (c) Cricket only = 20 − 7 = 13.
  5. Check: 13 + 7 + 11 + 4 = 35 ✓

Answer: x = 7. 13 students play cricket only.

Think: Why is it (20 − x) and not just 20 in the "cricket only" region?

Example 5.3

Expressions in the regions

The Venn diagram shows the number of elements in each region, and n(U) = 45. Find x, and then find n(P).

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Add all the regions: 2x + 5 + (x + 4) + x = 45.
  2. Collect like terms: 4x + 9 = 45.
  3. 4x = 36, so x = 9.
  4. n(P) = P only + both = 2x + 5 = 18 + 5 = 23.

Answer: x = 9 and n(P) = 23

Example 5.4

Three-set word problem

50 students were asked about three clubs: Maths (M), English (E) and Science (S). 20 are in M, 22 in E and 18 in S. 8 are in M and E, 6 in M and S, 7 in E and S, and 3 are in all three. How many students are in: (a) none of the clubs? (b) exactly one club? (c) exactly two clubs?

Try it in your book first. Then reveal the solution one step at a time and compare it with your working.

  1. Centre: 3.
  2. Pairs only (subtract the centre): M∩E only = 8 − 3 = 5. M∩S only = 6 − 3 = 3. E∩S only = 7 − 3 = 4.
  3. Singles only: M only = 20 − 5 − 3 − 3 = 9. E only = 22 − 5 − 4 − 3 = 10. S only = 18 − 3 − 4 − 3 = 8.
  4. In at least one club: 3 + 5 + 3 + 4 + 9 + 10 + 8 = 42. So none = 50 − 42 = 8.
  5. Exactly one: 9 + 10 + 8 = 27. Exactly two: 5 + 3 + 4 = 12.

Answer: (a) 8 (b) 27 (c) 12

Think: Why do we subtract the centre from each pair total before working out the "only" regions?

Common mistakes

  • Putting n(A) in the "A only" region. You must subtract the overlap first.
  • Forgetting the "neither" group when forming the equation.
  • In three-set problems, forgetting to subtract the centre from each pair total.
